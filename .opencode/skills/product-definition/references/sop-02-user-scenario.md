# SOP 02 - User Scenario

## Goal

把问题定义展开为用户场景、边界、流程和异常情况。

## Steps

1. 为核心用户列出主要场景、触发条件、前置条件和期望结果。
2. 描述主流程和关键分支，必要时转入 `expression-delivery` 生成流程图或用例图。
3. 标注边界：明确做什么、不做什么、以后可能做什么。
4. 记录非功能约束：性能、可靠性、安全、合规、可维护性、可访问性等。
5. 对每个场景给出可观察的验收信号。

## Validation

- 场景覆盖核心用户目标和主要异常。
- 没有把 UI 细节或技术选型写成业务需求。
- 验收信号能被后续设计和实现阶段引用。
