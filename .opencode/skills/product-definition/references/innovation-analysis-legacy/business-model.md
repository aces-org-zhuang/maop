# 商业模型画布与价值主张

## 商业模型画布 (Business Model Canvas)

### 九大构建模块

```
┌─────────────────────────────────────────────────────────┐
│                      合作伙伴                           │
│                       (Key Partners)                    │
├───────────────┬─────────────────────────┬───────────────┤
│   关键活动     │       价值主张          │   客户关系    │
│(Key Activities)│    (Value Propositions) │(Customer Rels)│
├───────────────┼─────────────────────────┼───────────────┤
│   关键资源     │                         │   渠道通路    │
│(Key Resources)│                         │ (Channels)    │
├───────────────┴─────────────────────────┴───────────────┤
│                       客户细分                           │
│                    (Customer Segments)                    │
└─────────────────────────────────────────────────────────┘

                        成本结构
                    (Cost Structure)

                        收入来源
                   (Revenue Streams)
```

### 详细说明

#### 客户细分 (Customer Segments)

**问题**：你在为谁创造价值？谁是你最重要的客户？

**类型**：
- 大众市场 (Mass Market)
- 利基市场 (Niche Market)
- 区隔化 (Segmented)
- 多元化 (Diversified)
- 多边平台 (Multi-sided Platform)

**示例**：
- 奢侈品牌 → 高净值人群
- 微信 → 大众 + 企业
- 亚马逊 → 消费者 + 第三方卖家

#### 价值主张 (Value Propositions)

**问题**：你在为客户解决什么问题？满足什么需求？

**价值类型**：
- 新颖 (Newness)
- 性能 (Performance)
- 定制化 (Customization)
- 品牌/身份 (Brand/Status)
- 价格 (Price)
- 成本降低 (Risk Reduction)
- 可达性 (Accessibility)
- 便利性/可用性 (Convenience/Usability)

**示例**：
- iPhone → 新颖 + 品牌 + 生态系统
- 宜家 → 价格 + 定制化 + 可达性
- Spotify → 可达性 + 便利性

#### 渠道通路 (Channels)

**问题**：如何触达客户？最佳组合是什么？

**渠道类型**：
- 自有渠道 (Own)
  - 销售团队
  - 网上商店
  - 直销
- 合作伙伴渠道 (Partners)
  - 分销商
  - 零售商
  - 联盟

**阶段**：
1. 认知 → 如何提升品牌认知？
2. 评估 → 如何帮助客户评估？
3. 购买 → 如何完成购买？
4. 交付 → 如何交付价值？
5. 售后 → 如何提供售后支持？

#### 客户关系 (Customer Relationships)

**问题**：建立什么类型的关系？各客户群体如何维护？

**关系类型**：
- 个人化 assistance (Personal Assistance)
- 专用个人 assistance (Dedicated Personal Assistance)
- 自助服务 (Self-Service)
- 自动化服务 (Automated Services)
- 社区 (Communities)
- 共创 (Co-creation)

**示例**：
- 高端银行 → 专属客户经理
-  Netflix → 自动化推荐 + 社区
- 微信 → 社区 + 自服务

#### 收入来源 (Revenue Streams)

**问题**：客户愿意为什么价值付费？收入模式是什么？

**收入模式**：
| 模式 | 描述 | 示例 |
|------|------|------|
| 资产销售 | 物理产品所有权 | 汽车、书籍 |
| 使用费 | 使用服务付费 | 打车、住宿 |
| 订阅费 | 定期付费获取服务 | 会员、云计算 |
| 授权费 | IP/技术授权 | 专利、配方 |
| 经纪费 | 撮合交易收费 | 房产中介、电商平台 |
| 广告费 | 为曝光付费 | 搜索、社交媒体 |

**定价机制**：
- 固定定价 (目录价)
- 动态定价 (实时调整)
- 反向拍卖 (用户出价)
- 竞价 (拍卖)

#### 关键资源 (Key Resources)

**问题**：价值主张需要什么核心资源？

**资源类型**：
- 物理资源 (Physical)
- 知识资源 (Intellectual)
- 人力资源 (Human)
- 财务资源 (Financial)

#### 关键活动 (Key Activities)

**问题**：价值主张需要什么关键活动？**

**活动类型**：
- 生产制造 (Production)
- 解决方案 (Problem Solving)
- 平台/网络 (Platform/Network)

#### 关键合作伙伴 (Key Partners)

**问题**：谁是你的关键合作伙伴？供应商？

**合作动机**：
- 优化 (Optimization)
- 降低风险/不确定性 (Risk/Reduction)
- 特定资源/活动获取 (Resources/Activities)

**合作伙伴类型**：
- 战略联盟
- 竞合 (Co-opetition)
- 合资
- 供应商

#### 成本结构 (Cost Structure)

**问题**：什么是关键成本？什么活动/资源最贵？**

**成本导向**：
- 成本驱动 (Cost-Driven)
- 价值驱动 (Value-Driven)

**特征**：
- 固定成本 vs 可变成本
- 规模经济 vs 范围经济

## 价值主张画布 (Value Proposition Canvas)

### 结构

```
┌─────────────────────┬─────────────────────┐
│    客户 Profile     │     价值 Map        │
├─────────────────────┼─────────────────────┤
│ Jobs (任务)         │ Products & Services │
│ - 功能性任务        │ (产品与服务)         │
│ - 社会性任务        │                     │
│ - 情感性任务        │ Gain Creators       │
│ - 辅助性任务        │ (收益创造)           │
├─────────────────────┼─────────────────────┤
│ Pains (痛点)        │ Pain Relievers      │
│ - 功能性痛点        │ (痛点消除)           │
│ - 情感性痛点        │                     │
│ - 隐性成本          │                     │
└─────────────────────┴─────────────────────┘
```

### Fit 的三个层面

1. **Jobs-to-be-Done Fit** - 产品帮助客户完成任务
2. **Value Proposition Fit** - 价值主张解决客户痛点
3. **Demand-Value Fit** - 客户真正愿意付费

### 使用流程

```
1. 识别客户 Jobs
2. 识别客户 Pains
3. 识别客户 Gains
4. 设计价值 Map
5. 连接 Profile ↔ Map
6. 验证 Fit
```

## 实际应用

### 设计新商业模型

1. **识别痛点** - 市场/客户有什么未满足需求？
2. **定义价值主张** - 如何解决这个痛点？
3. **构建模块** - 按顺序填充九宫格
4. **验证假设** - 哪些需要验证？
5. **迭代优化** - 根据反馈调整

### 评估现有商业模型

1. **地图绘制** - 用画布描述现有模型
2. **问题识别** - 哪些模块薄弱？
3. **机会识别** - 哪些可以做创新？
4. **实验设计** - 如何测试变化？
5. **实施跟踪** - 监控影响

### 商业模型创新类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 利润模式创新 | 改变收入方式 | 订阅制 |
| 网络模式创新 | 利用网络效应 | 平台 |
| 结构模式创新 | 优化价值链 | 外包 |
| 体验模式创新 | 改变客户体验 | 体验店 |
