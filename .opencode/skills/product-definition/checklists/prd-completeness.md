# PRD Completeness Checklist

- [ ] 覆盖问题、用户、场景、范围和成功标准。
- [ ] 已定义核心角色、次要角色和排除角色；没有用泛泛“用户”替代角色。
- [ ] 核心 Use Case 覆盖触发条件、前置条件、目标、主路径、关键分支和验收信号。
- [ ] 每个核心功能需求都能追溯到至少一个角色和 Use Case。
- [ ] 功能需求和非功能需求分开描述。
- [ ] 验收标准可测试。
- [ ] 风险和依赖明确。
- [ ] 已覆盖 User/Use Case、Acceptance/Risk、Market/Alternative、Scope/Revision lens。
- [ ] 如使用委派结果，已完成 Delegation Quality Gate、Synthesis Gate 和 fallback 记录。
- [ ] Product Handoff Packet 已按字段级吸收规则整理：原始输入、角色、Use Case、范围、需求、验收、风险、市场替代、假设、开放问题、Reuse Ledger 和 readiness。
- [ ] 能被 technical-design 直接消费。
