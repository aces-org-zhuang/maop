# Knowledge Discovery

统一承接外部知识、技术链接、微信文章、工具/skill 发现和轻量知识库构建。

## 迁移来源

- 技术链接发现与趋势分析资产迁入 `references/technical-sources/` 和 `tools/`。
- 微信文章提取、安全和输出格式资产迁入 `references/wechat-extraction/`。
- Skill 生态查找和安装规则迁入 `references/skills-ecosystem/`。

## 路由边界

- 深度研究、论文、证据包和研究工作区：转入 `research`。
- 开源仓选型、候选对比、submodule 治理：转入 `github-selection`。
- 图表、slides、原型、图片和视觉表达：转入 `expression-delivery`。
- 自建新 skill：转入 `skill-creator`。
