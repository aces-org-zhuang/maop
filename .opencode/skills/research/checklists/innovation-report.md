# Innovation Report Checklist

- [ ] 报告明确以技术问题与技术方案论证为主线。
- [ ] 第 2 章包含现实背景、需求、痛点、约束和最小必要市场支撑。
- [ ] 第 2 章的所有量化数据都标注了来源或内部估算说明。
- [ ] 第 3 章包含业界现有技术方案及对比表。
- [ ] 第 4 章说明创新方案与痛点的对应关系和差异化创新点。
- [ ] 第 5 章按步骤展开，且每步字段完整。
- [ ] 第 6 章包含 baseline、target、measurementMethod、estimatedImpact。
- [ ] 第 7 章包含技术壁垒、可绕过性和技术取证方法。
- [ ] 第 8 条呈现约束已落实，图表服务于论证而非装饰。
- [ ] 已执行 Preview Gate。
- [ ] 复杂技术论证已执行 Reasoning Gate。
- [ ] 定版前 Review Gate >=80。
- [ ] 完成声明前有 evidence。
