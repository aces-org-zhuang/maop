# SOP 04: Innovation Discovery

用于创新方法论、创新机会识别、TRIZ、蓝海战略、设计思维、精益创业、开放创新等请求。

## Outputs

- `{research_root}/innovation/methodology.md`
- `{research_root}/innovation/opportunities.md`
- `{research_root}/innovation/assumptions.md`
- `{research_root}/innovation/validation-plan.md`

## Method Selection

- 用户需求不明确：Design Thinking、JTBD、用户旅程。
- 产品方向模糊：Lean Startup、MVP、假设验证。
- 市场竞争激烈：Blue Ocean、战略画布、四步动作。
- 技术矛盾突出：TRIZ、矛盾矩阵、40 条发明原则。
- 商业模式创新：Business Model Canvas、价值主张画布。
- 生态和开放协作：Open Innovation、平台生态、伙伴网络。

## Innovation Flow

```text
机会识别 -> 创意生成 -> 原型验证 -> 商业建模 -> 规模化实施
```

## Method Combinations

- 新产品开发：Design Thinking 用户洞察 + Lean Startup MVP 验证 + Business Model Canvas 盈利建模。
- 技术突破：TRIZ 系统分析 + 快速原型验证 + Stage-Gate 阶段治理。
- 市场创造：Blue Ocean 价值曲线 + Platform Strategy 生态系统 + Crossing the Chasm 市场推广。

## Checks

- 创新类型已明确：产品、流程、商业模型或服务。
- 创新程度已明确：渐进、突破或颠覆。
- 约束条件已明确：资源、时间、技术、市场。
- 创意是否解决真实用户痛点。
- 是否具有可行性验证路径。
- 是否规划了最小验证和成功标准。

## Discovery Coupling

- 方法论用于指导关键词、来源类型、证据结构和机会判断维度。
- 需要外部材料时调用 Discovery Path 或 Weixin Search Path。
- 需要产品定义或 PRD 时，把机会产物转入 `product-definition`。
