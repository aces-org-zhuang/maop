# SOP 02: Discovery

用于外部资料、技术链接、趋势、学习资源、知识库、tool/skill 查找。

## Outputs

- `{research_root}/discovery/search-plan.md`
- `{research_root}/discovery/technical-sources.md`
- `{research_root}/discovery/skills-tools.md` when tool/skill discovery is requested
- `{research_root}/sources/source-index.md`
- `{research_root}/sources/links.md`

## Rules

- 执行检索前先读取 `paths/sop-retrieval-reasoning.md`，按扩展检索 -> 收敛证据 -> 围绕 RED 点再扩展 -> 再收敛的循环推进。
- 不把搜索结果原样堆叠，必须去重、分类、标注来源和价值。
- 外部资料结论必须可追踪到链接或来源描述。
- 对趋势判断标注时间窗口和证据质量。
- 对 third-party skill 安装命令标注作用域和风险；安装前必须确认。
- 技术选型决策转入 `technical-design`，本 path 只负责发现候选和资料。
- `{research_root}/discovery/search-plan.md` 必须记录每轮检索扩展范围、收敛依据、删除来源原因和未闭环 RED 点。
