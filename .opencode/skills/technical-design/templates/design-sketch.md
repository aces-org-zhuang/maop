# ASCII Design Sketch

```text
Design Sketch
  Requirement Trace
    -> <requirement or acceptance signal>

  Existing Context
    -> <current module / contract / data source, or explicit unknown>

  Proposed Components
    -> <generic component A> -> <generic component B>

  Data and State
    -> <input data>
    -> <state transition>
    -> <output / persisted state>

  Change Boundary
    In
      -> <files or modules to change>
    Out
      -> <files or modules not to change>

  Risks
    -> <risk and why it matters>

  Verification
    -> <test, build, smoke, or manual check>
```

Do not insert project-specific paths, product names, runtime systems, gateways, or toolchain names unless the user input explicitly provides them.
