# SOP 00 - Intake

## Goal

确认技术设计输入是否充分，并确定当前设计阶段。

## Steps

1. 读取用户提供的需求、PRD、任务记录、设计草案或错误背景。
2. 检查项目是否已有架构文档、设计模板、接口契约、编码规则或平台抽象。
3. 判断设计范围：新功能、改造、重构、接口变更、数据变更、风险评估或设计评审。
4. 若需求本身不清，回到 `product-definition`，不要用设计假设补需求缺口。
5. 若缺少代码仓或必要上下文，列出阻塞项；若可通过只读探索获得，先探索再判断。

## Outputs

- 设计范围。
- 已有材料和项目约束。
- 下一阶段 SOP。
- 阻塞项或待确认问题。
